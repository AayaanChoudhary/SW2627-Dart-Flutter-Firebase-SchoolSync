1. Project Title

School District Monitoring System

2. Project Overview

A mobile application for school districts to monitor attendance, fee collections, and examination schedules across multiple schools.

The system provides a centralized view of school-level information so that district administrators can identify issues such as attendance crises and fee shortfalls earlier, rather than waiting for periodic reviews.

The application will be developed as an Android mobile application using Flutter and Firebase.

3. Problem Statement

Currently, schools report attendance, fee collections, and examination information to the district office only during periodic reviews. This makes it difficult for the district to identify problems at individual schools in time.

The system aims to provide a centralized platform where authorized school users can maintain relevant information and district-level users can monitor it more efficiently.
